Jersey Demo - User Profile Settings API

Welcome to the Jersey REST API demo. This application provides endpoints for managing user profile settings.

Available Endpoints:

GET /api/users/health

Health check endpoint

GET /api/users

Get all user profiles

GET /api/users/{userId}/profile

Get user profile by ID

POST /api/users/{userId}/profile

Create or replace user profile

PUT /api/users/{userId}/profile

Update user profile settings (partial update)

DELETE /api/users/{userId}/profile

Delete user profile

Example Usage:

Try accessing: api/users/1/profile
